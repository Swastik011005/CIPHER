# Archive

Working notes from the development of CIPHER, kept for traceability. They are **not** part of the user-facing documentation and
are not kept up to date.

| File | What it is |
|---|---|
| `FINAL_EXECUTION_PROGRESS.md` | The agent's running log of the final execution pass (what was built, measured and verified, and the commands to continue). |
| `FINAL_EXECUTION_RESUME_PROMPT.md` | The hand-off note used to resume that pass in a new session. It still shows the original local folder path and an earlier "do not push" rule, which no longer applies. |

For the current state of the project, read the [README](../../README.md), the
[user manual](../CIPHER_USER_MANUAL.md) and the [final technical report](../CIPHER_FINAL_TECHNICAL_REPORT.md).
